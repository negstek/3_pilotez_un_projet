# DataShare — Guide de l'utilisateur

DataShare sert à transmettre un fichier à quelqu'un par un simple lien. Vous déposez le fichier, vous recevez un lien, et la personne qui le reçoit télécharge le fichier sans avoir besoin de compte. Le lien fonctionne pendant une durée limitée, de 1 à 7 jours.

Un compte n'est pas obligatoire. Il sert à retrouver vos fichiers et à les supprimer.

| Ce que vous voulez faire | Compte nécessaire |
|---|---|
| Déposer un fichier et obtenir un lien | Non |
| Télécharger un fichier reçu par lien | Non |
| Retrouver la liste de vos fichiers | Oui |
| Supprimer un fichier | Oui |

## Déposer un fichier

1. Ouvrez la page d'accueil et cliquez sur le bouton rond sous « Tu veux partager un fichier ? ».
2. Choisissez le fichier sur votre ordinateur. Le bouton « Changer » permet d'en choisir un autre.
3. Si vous le souhaitez, saisissez un **mot de passe** : il sera demandé à toute personne qui voudra télécharger le fichier.
4. Choisissez la durée dans la liste **Expiration**, d'une journée à une semaine. Une semaine est proposée par défaut.
5. Cliquez sur « Téléverser ».

Le lien de partage s'affiche. Le bouton « Copier le lien » le place dans le presse-papiers : collez-le dans un email ou un message.

Si vous avez protégé le fichier, transmettez le mot de passe par un autre moyen que le lien, par exemple par téléphone.

### Limites

| Règle | Valeur |
|---|---|
| Taille d'un fichier | 1 Go au maximum |
| Types refusés | Programmes et scripts : `.exe`, `.bat`, `.cmd`, `.com`, `.msi`, `.scr`, `.ps1`, `.vbs`, `.sh`, `.jar` |
| Mot de passe du fichier | Facultatif ; 6 caractères au minimum |
| Durée du lien | De 1 à 7 jours |

### Avec ou sans compte

- **Connecté**, le fichier est rattaché à votre compte : vous le retrouvez dans « Mes fichiers » et vous pouvez le supprimer.
- **Sans compte**, le fichier n'est rattaché à personne. Conservez bien le lien : il est impossible de le retrouver ensuite, et le fichier ne peut pas être supprimé avant son expiration.

## Télécharger un fichier

1. Ouvrez le lien que vous avez reçu. La page affiche le nom du fichier, sa taille et le temps restant avant l'expiration.
2. Si le fichier est protégé, saisissez le mot de passe que l'expéditeur vous a communiqué.
3. Cliquez sur « Télécharger ».

## Créer un compte et se connecter

- **Créer un compte** : cliquez sur « Se connecter » en haut de la page, puis sur le lien de création de compte. Saisissez votre email et un mot de passe d'au moins 8 caractères, deux fois. Vous arrivez connecté sur votre espace.
- **Se connecter** : cliquez sur « Se connecter », puis saisissez votre email et votre mot de passe.
- **Se déconnecter** : dans votre espace, cliquez sur « Déconnexion ».

La session dure un jour. Passé ce délai, l'application vous demande de vous reconnecter.

## Gérer ses fichiers

Une fois connecté, le bouton « Mon espace » ouvre la page « Mes fichiers ». Chaque ligne indique le nom du fichier, sa taille, sa date d'envoi et son expiration. Un cadenas signale un fichier protégé par un mot de passe.

- **Filtrer** : le sélecteur « Tous / Actifs / Expiré » choisit les fichiers affichés. Par défaut, seuls les fichiers actifs apparaissent.
- **Retrouver le lien** : « Accéder » ouvre la page de téléchargement du fichier, dont vous pouvez copier l'adresse.
- **Supprimer** : « Supprimer » retire définitivement le fichier après confirmation. Son lien cesse aussitôt de fonctionner. La suppression est irréversible.
- **Déposer un autre fichier** : « Ajouter des fichiers » ramène à la page d'accueil.

Un fichier expiré reste affiché avec la mention « Ce fichier a expiré ». Son lien ne fonctionne plus et il ne peut pas être prolongé : déposez-le à nouveau pour obtenir un nouveau lien.

## En cas de problème

| Ce que vous voyez | Ce que cela signifie | Que faire |
|---|---|---|
| « La taille des fichiers est limitée à 1 Go » | Le fichier est trop volumineux | Compressez-le ou découpez-le en plusieurs fichiers |
| « Ce type de fichier n'est pas autorisé » | L'extension fait partie des types refusés | Placez le fichier dans une archive `.zip` |
| « Ce fichier n'est plus disponible en téléchargement car il a expiré » | La durée du lien est dépassée | Demandez à l'expéditeur de déposer le fichier à nouveau |
| Le lien affiche une erreur dès l'ouverture | Le lien est incomplet, ou le fichier a été supprimé | Vérifiez que le lien a été copié en entier, sinon contactez l'expéditeur |
| Le mot de passe du fichier est refusé | Le mot de passe saisi n'est pas le bon | Vérifiez les majuscules ; redemandez-le à l'expéditeur |
| « Votre session a expiré : reconnectez-vous pour téléverser un fichier. » | Votre connexion a plus d'un jour | Reconnectez-vous, puis recommencez le dépôt |
| Mot de passe du compte oublié | L'application ne propose pas de réinitialisation | Créez un compte avec une autre adresse email |
